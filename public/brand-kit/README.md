# Accounting · Trace Loop logo kit

Direction A, approved by the project owner. This kit contains production artwork for the Accounting Digital Operations workspace.

## Start here

- `guidelines.md` — usage, clear space, colour, size, and type rules.
- `handover-notes.md` — construction, review results, and remaining checks.
- `source/` — outlined SVG masters for the mark and lockups.
- `digital/` — one-colour and reversed SVGs, browser/PWA icons, and raster exports.
- `print/` — vector SVG masters for print vendors.
- `presentation/` — final refinement board and visual overview.

The horizontal lockup is the default for website headers and documents. Use the symbol alone for the browser tab, app tile, profile, or compact navigation. Use reversed artwork on the approved Indigo field.
